# CRM with Integrated Inventory Management

## Project Overview
A Python-based application to manage customer details, products, orders, and inventory in one place.

## Features
- Add and manage customers
- Add and manage products
- Track inventory and stock levels
- Create and view customer orders
- Automatically update stock after placing orders
- Store data using SQLite

## Technologies Used
- Python
- SQLite3

## How to Run
1. Download or clone this repository.
2. Install Python 3.8 or later.
3. Open the project folder in the terminal.
4. Run the command:

   python main.py

The database is created automatically when the application runs for the first time.
